🎀 Blossom & Bow | Cute Boutique & Lifestyle Store

Welcome to Blossom & Bow (https://lavanyasaisri-max.github.io/Blossom-Bow/), an adorable, modern, and fully interactive single-page e-commerce web application built with a cozy pastel aesthetic! 🌸✨

📸 Preview & Live Demo

Live Website: https://lavanyasaisri-max.github.io/Blossom-Bow/

✨ Key Features

🌸 Pastel & Cute Aesthetic: Styled with soft pinks, lavenders, mints, and warm typography (Quicksand & Inter) to create a welcoming shopping experience.

🛍️ Interactive Shopping Bag & Drawer: Slide-over cart drawer with real-time quantity adjustments, subtotal calculations, and item removals.

🔍 Instant Search & Category Filtering: Quickly filter products by categories (Electronics, Apparel, Home & Living, Accessories) or search in real time.

⚡ Sorting Options: Sort items by featured status, price (low to high & high to low), or highest customer ratings.

🔎 Quick View Modal: Click on any product card or "Quick View" button to inspect detailed descriptions, star ratings, and review counts.

🎁 Flash Sales & Countdown Timer: Special promotional section featuring limited-time deals accompanied by a live countdown timer.

💳 Secure Checkout Modal: Simulated checkout form for smooth order placement with instant success confirmation toasts.

📱 Fully Responsive: Perfectly optimized for mobile phones, tablets, and desktop computers with a clean hamburger navigation menu.

🛠️ Built With

HTML5 & Modern CSS

Tailwind CSS v4 (via CDN for rapid utility-first styling)

FontAwesome 6 (for icons)

Google Fonts (Quicksand & Inter)

Vanilla JavaScript (for interactive state management, cart handling, filtering, and modals)

🚀 Quick Start / Local Setup

Because this project is built as a single, self-contained HTML file, you don't need any complicated build tools or Node.js to run it!

Clone or download this repository:

git clone https://github.com/lavanyasaisri-max/Blossom-Bow.git


Navigate into the project folder.

Open index.html directly in any web browser of your choice, or use a live server extension (like Live Server in VS Code).
